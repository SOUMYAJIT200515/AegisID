# Contributing to AegisID

First off, thank you for considering contributing to **AegisID**! 

AegisID is a prototype built for the **Smart India Hackathon (SIH) 2026**, focusing on decentralized identity, verifiable credentials, role-based access control, and blockchain-backed digital asset management. We welcome contributions that help improve the platform's security, performance, and features.

## 📜 Code of Conduct

By participating in this project, you are expected to uphold a welcoming and collaborative environment. Please treat all contributors with respect, provide constructive feedback, and focus on the project's goals.

---

## 🚀 Getting Started

Before you begin contributing, ensure you have the local development environment set up. 

AegisID requires three main services to run concurrently:
1. **Blockchain Network** (Hardhat local node)
2. **Backend API** (Java 17 + Spring Boot)
3. **Frontend UI** (React + Vite)

Please refer to the **Local Setup** section in our [README.md](README.md) for detailed prerequisites and installation steps.

## 🛠️ How Can I Contribute?

### Reporting Bugs
If you find a bug, please open an issue in the repository. Include the following details to help us fix it quickly:
*   A clear and descriptive title.
*   Steps to reproduce the bug.
*   Expected vs. actual behavior.
*   Screenshots (if applicable).
*   Your environment details (OS, Node version, Java version).

### Suggesting Enhancements
Have an idea to make AegisID better? We'd love to hear it! Open an issue and provide:
*   A clear summary of the feature.
*   The problem it solves or the value it adds to the SIH prototype.
*   Any relevant examples or mockups.
